# 需要手動輸入的項目(不會被備份)

這些東西刻意**不**寫進隨身硬碟,請記在密碼管理器或自己知道的地方。
復原時由你本人輸入,AI 不應該要求你把密碼貼進對話裡。

| 項目 | 何時需要 | 備註 |
|---|---|---|
| Apple ID 密碼 + 兩步驟驗證 | 重置後設定助理 | 登入後 iCloud 鑰匙圈會帶回 Wi-Fi 密碼 |
| Mac 登入密碼 | 執行 `sudo` 步驟 | 重置後自行設定 |
| Parsec 帳號 Email / 密碼 | 開啟 Parsec 時 | 原本的登入權杖 `user.bin` 沒有備份 |
| Parsec 兩步驟驗證(2FA)/ 備用碼 | 登入 Parsec 時 | 確認手機驗證 App 還在 |
| Wi-Fi 密碼 | 若沒用 iCloud 鑰匙圈 | 網路名稱在 `network/wifi-preferred-networks.txt` |
| Steam / 遊戲平台帳號 | 有在用時 | Steam Guard 驗證 |
| Sunshine / Moonlight 配對 PIN | 有在用時 | 配對憑證沒備份,需重新配對 |
| Tailscale / ZeroTier 登入 | 有在用時 | 重新登入後裝置名稱可能要改回來 |
| SSH 私鑰 | 有在用時 | 未備份;用加密方式另存或重新產生 |
| 付費 App 授權碼(例如 BetterDisplay Pro) | 有在用時 | 通常在購買信件裡 |

## 其他需手動處理(macOS 不允許腳本自動設定)

- 隱私權限:螢幕錄製、輔助使用、麥克風、輸入監控、完整磁碟取用權限
- 安裝系統延伸功能/驅動時的「允許」按鈕(系統設定 > 隱私權與安全性 最下方)
- 防火牆第一次跳出的「允許傳入連線」
